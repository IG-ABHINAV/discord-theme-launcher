# 0.3.0 beta 6 — Vencord repair

Discord no longer opens the "Cannot find module patcher.js" error when the Vencord stub is still installed and the runtime files are gone. Opening the launcher repairs that state with the official Vencord installer, then starts Discord only after `patcher.js` is present. If the repair does not finish, the local official Discord package is restored from `_app.asar`.

- The installer remains the pinned official CLI 1.4.2, verified by SHA-256 before it runs.
- A working Vencord install is left unchanged. First-time installation during Apply still asks for consent.
- Existing `.dtheme` files and theme CSS stay compatible. This build only changes the launcher.

Checks: 61 core, 41 browser and 37 native Windows checks; Release packaging. Core checks cover the missing-module stub, official-package restoration, and a present `patcher.js`. On the maintainer machine the official repair restored the runtime files and Discord opened. Automated tests do not modify a real Discord profile. Clean-machine first install, signing and exhaustive accessibility/performance coverage remain open.

Close an older launcher before opening this Windows x64 beta. WebView2 Runtime is required; .NET, editor assets and notices are bundled. The executable remains unsigned. Changes affect the local client only; other members adopt shared configurations themselves.
