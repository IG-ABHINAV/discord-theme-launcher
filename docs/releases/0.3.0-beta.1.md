# 0.3.0 beta 1 — Your server, your theme

Discord Theme Launcher becomes a Windows configurator for a server you choose. Start with Prime Build, Prime Build Dev or FantaFort, paste a server ID/channel link, then choose typography, palette, banner and background.

- Live local preview with synthetic content and server/DM isolation controls.
- Bundled fonts, original artwork, four palettes and custom colors.
- PNG/JPEG image import and licensed static TTF/OTF import with bounded formats/sizes and integrity checks.
- Save, reopen and share `.dtheme` configurations with selected assets and font licenses embedded.
- One personal theme slot with apply, disable and reversible restore. Existing community presets and three-file backups remain usable.
- Other themes, plugins, QuickCSS and unrelated preferences are preserved. Conflicting bundled presets are disabled only for the chosen personal target.

**Local client only:** other members must choose to apply a shared configuration themselves. No Discord token, credentials, bot or server permissions are requested.

Download and extract the **Windows x64 portable ZIP**, then run `DiscordThemeLauncher.exe` normally. It bundles .NET, presets and notices. The embedded preview requires **Microsoft Edge WebView2 Runtime**; if absent, install it from Microsoft's official site. Optional official Vencord installation/repair requires Internet access and explicit consent. Applying, disabling and restoring restart Discord only after the calls/drafts acknowledgement.

Validation: 57 Windows core checks (58 Linux), 27 browser tests and 13 native Windows integration checks; Release packaging. Personal transactions use isolated profiles. The user's running Discord was not restarted, and fresh-machine full installation/restart testing remains open. See [Validation](https://github.com/PrimeBuild-pc/discord-theme-launcher/blob/main/docs/VALIDATION.md).

The EXE is **unsigned**. Review source and `SHA256SUMS.txt`. Windows x64 / standard per-user stable Discord / default Vencord only. One personal theme at a time; no arbitrary CSS, SVG, variable-font or font-collection import. The preview approximates supported Discord layouts. Gaming/call benchmarks and exhaustive accessibility/layout coverage remain open.

Vencord is unofficial and has Discord terms/account implications. This independent project is not affiliated with Discord, Vencord or Epic Games. Original source/artwork is MIT; bundled fonts and runtime components retain their notices. Imported assets retain their owners' licenses.
