# 0.3.0 beta 3 — Know what Apply needs

Apply now explains exactly why it is disabled, beside the button. Choosing a preset alone is insufficient: the design must load, a supported Discord/Vencord setup must be ready (or official setup explicitly selected), and calls/drafts must be acknowledged before restarting.

- Missing Vencord offers **Set up Vencord**, opening Recovery.
- Missing restart acknowledgement offers a link to focus the unchecked checkbox.
- Missing desktop Discord, preview mode, elevation, profile errors and preview/configuration problems receive specific explanations.
- Enabled state and explanation come from the same readiness result. Installation/restart consent and existing safety gates are retained.

This package also includes the existing main-branch Prime Build background refinement: the board image appears only when the chat has room.

Checks: 57 core, 38 browser and 36 Windows tests, plus Release packaging. The original report concerns a friend's machine; its exact missing prerequisite is unconfirmed. This update fixes the reproduced lack of guidance and does not claim remote validation or support for other Discord variants.

Close the previous launcher before opening this version. Existing configurations remain compatible. Windows x64 / standard per-user stable Discord / default Vencord only. WebView2 Runtime is required. The executable remains unsigned; review release checksums. The user's working Discord was not restarted during development.
