# 0.3.0 beta 11 — Theme Studio

Create, edit, preview and share a Discord theme for the servers and private chats you choose. This release brings the editor, community templates, compatible BetterDiscord import and reusable local libraries together.

## Download and run

Download **DiscordThemeLauncher-0.3.0-beta.11-windows-x64-portable.zip**, extract it and run `DiscordThemeLauncher.exe` normally. The ZIP includes licenses and a quick-start guide. A standalone EXE is also available. Both are self-contained .NET builds; Microsoft Edge WebView2 Runtime is required.

The three standalone `.theme.css` assets remain optional fixed-server presets for Prime Build, Prime Build Dev and FantaFort. Use the launcher to retarget a design, edit Zenit Gold or create your own theme. `catalog.json` describes those preset assets; `SHA256SUMS.txt` covers every other release asset.

## What's new since beta 6

- **One editor:** Server, Style, Artwork and Files beside the live preview. Templates includes an empty Fluent Dark design, Prime Build, Prime Build Dev, FantaFort and **Zenit Gold — by JACKPOT71**, with its original design, MIT credit and reviewed offline resources.
- **Reusable customization:** named local themes, three-color palettes, image libraries, actual artwork thumbnails and 64 searchable fonts downloaded on selection. Custom static font import remains available.
- **Compatible BetterDiscord import:** import downloaded CSS or theme folders, review compatibility, edit supported variables and preserve source, assets and licensing in portable `.dtheme` files. Import is a supported subset, not universal compatibility.
- **Explicit targets:** up to 16 servers and 16 specific DM channel IDs per theme. DM preview shows a private conversation; styling requires supported visible message markers and stays off when detection fails.
- **Clear saves and session recovery:** saved checks, no redundant Save action, local profile duplication/renaming, and Save and close / Discard / Keep editing. Reopen the last clean document, editor section and preview context.
- **Simpler recovery:** embedded reset choices for launcher themes only or all styling, plus selectable previous setups. Files and plugins are preserved.
- **Polished Windows UI:** application/taskbar icon, embedded guidance and five languages including German, with translated illustrative previews.
- **Community proposals:** a user-submitted GitHub issue form for human review; no automatic file upload or pull request.

## Upgrade notes

Close the older launcher before replacing its portable files. Existing schema-one `.dtheme` files, local libraries and recovery snapshots remain compatible. User data stays under `%LOCALAPPDATA%\PrimeBuild\DiscordThemeLauncher`; it is not stored beside the EXE.

**Apply now enables only the current launcher theme on its selected targets.** Other launcher presets are disabled, with their files retained. External themes remain enabled and may still affect appearance. A recovery snapshot preserves the preceding managed setup.

Theme changes remain local to your client. Other members choose whether to adopt an exported theme themselves.

## Validation and known limits

- **128 Windows Core checks, 66 Chromium tests and 71 native Windows/WebView2 checks passed.** Linux and Windows CI verify the source and portable packaging.
- Native tests cover final pending keystrokes, save/discard/cancel close, fresh-session restoration, palette drafts and failed-save handling. Automated tests use temporary profiles and synthetic conversations.
- Supported automatic setup is Windows x64, per-user stable Discord and the default Vencord profile. The EXE is **unsigned**. No signing certificate is bundled or security setting bypassed.
- Live DM application, Windows reboot/power-cycle behavior, clean-machine installation and exhaustive assistive-technology coverage remain unverified. Discord layout updates can prevent guarded themes from activating. Not every BetterDiscord theme is compatible.
