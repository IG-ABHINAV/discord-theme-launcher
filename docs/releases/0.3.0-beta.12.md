# 0.3.0 beta 12 — Saved themes and clearer application

Reuse a saved design, make a small change, and choose its servers without recreating the theme. This release also improves personal Vencord cards and fixes startup, memory and recovery issues.

## Download and upgrade

Download **DiscordThemeLauncher-0.3.0-beta.12-windows-x64-portable.zip**, extract it and run `DiscordThemeLauncher.exe` normally. Close the previous launcher before opening the new one. Your local theme library, session and recovery snapshots stay in your Windows user profile.

The ZIP includes licenses and a quick-start guide. The standalone EXE is also available. Both bundle .NET and require Microsoft Edge WebView2 Runtime. The executable remains **unsigned**.

## What's new

- **Home → Use a saved theme** goes straight to My themes. Each saved design offers **Open in editor** and **Duplicate theme…**. Duplicating a saved design preserves the original and your open draft.
- **Save theme** keeps the editable design in your local library. **Review & apply** opens the confirmation before updating Discord. Helper text explains adding a server while keeping existing target IDs.
- Personal Vencord cards show the theme's chosen name and **by you**. Add an optional description in the editor to show it on the card after application. Imported designs retain their original author credit.
- Opening the editor no longer automatically downloads an installer or closes Discord to repair Vencord. Installation and repair require setup consent in the reviewed application flow.
- Completed embedded-browser resource buffers can be released. A malformed recovery snapshot no longer prevents healthy snapshots from appearing. Busy operations disable edits that the native host cannot accept.

## Application behavior

The current design applies to the **complete list of selected servers and DM chats**. It replaces the active personal design and disables older launcher presets; their files and saved designs remain available. It does not create a separate active slot for each saved theme. Review shows this before confirmation. Changes affect only your local Discord client.

## Validation

The release checks cover build and stylesheet checks, 139 Core checks, 83 Windows checks and 71 browser tests. Windows tests use actual WebView2 windows and temporary profiles; client application is simulated. The local PC's themes were also confirmed to survive a PC restart, with Discord starting without the previous crash. This is local validation, not a guarantee for every installation.

The three `.theme.css` assets are optional fixed-server presets. `catalog.json` describes them; `SHA256SUMS.txt` covers every other release asset. No theme-document migration is required.

See the [installation and recovery guide](https://github.com/PrimeBuild-pc/discord-theme-launcher/blob/v0.3.0-beta.12/docs/INSTALLATION.md) and [theme format and application behavior](https://github.com/PrimeBuild-pc/discord-theme-launcher/blob/v0.3.0-beta.12/docs/CONFIGURATIONS.md).
