# 0.3.0 beta 5 — Italian, Spanish and Russian

The launcher interface now includes Italian, Spanish and Russian. English stays the default. The choice is in the header language menu and is remembered for the Windows user. Theme files, shared configurations and all documentation stay in English.

- Product names such as Prime Build, Prime Build Dev, FantaFort, Discord and Vencord stay as names.
- Cyrillic uses the bundled Noto Sans, or Segoe UI when an installed gg sans face has no Cyrillic glyphs.
- Existing `.dtheme` files remain compatible. The language setting is not part of a shared theme.

Checks: 57 core, 41 browser and 37 native Windows checks; Release packaging. Language tests use the shipped page and the real WebView2 host, then return to English. No real Discord writes or restart. Clean-machine Vencord setup/live application, signing and exhaustive accessibility/performance coverage remain open.

Close an older launcher before opening this Windows x64 beta. WebView2 Runtime is required; .NET, editor assets and notices are bundled. The executable remains unsigned. Changes affect the local client only; other members adopt shared configurations themselves.
