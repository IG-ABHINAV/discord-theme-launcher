# 0.3.0 beta 15 — Several themes, each on its own servers

Different themes can now stay enabled at the same time, for example one design per server. My themes shows which ones are active and lets you switch them on or off, or delete them, in one click.

## Changes

- Each saved theme is written to its own Vencord file (`Studio-<id>.theme.css`). Enabling, disabling or applying one theme never disables the others.
- My themes shows an **Active / Inactive** badge per theme with quick **Enable**, **Disable** and **Delete** (two-step) buttons. Discord restarts only if it is open, because Vencord owns its settings while running. Every change saves a recovery snapshot.
- **Review & apply** saves the open theme in My themes and enables it for its complete target list; other enabled themes stay active.
- Enabled files from older launcher versions are kept and rewritten to the faster style-gated format from beta.14. A legacy personal slot holding the same design is replaced by its per-theme file.

## Upgrade

Download **DiscordThemeLauncher-0.3.0-beta.15-windows-x64-portable.zip**, extract it and run `DiscordThemeLauncher.exe`. Open each saved theme you want in Discord and choose **Enable** in My themes (or Review & apply). Local libraries, configurations and recovery history are preserved.

Both the ZIP and the standalone EXE bundle .NET, require Microsoft Edge WebView2 Runtime and remain **unsigned**.
