# 0.3.0 beta 4 — Preview, confirm, apply

Editing is always a preview. **Apply to Discord** now opens an overlay matching Theme Studio, with the exact theme and target server. **Continue & apply** authorizes application and the Discord restart; **Back to preview** or Esc cancels without applying.

- No separate preview-only product mode to close/reopen.
- No preliminary restart checkbox in the main editor. The confirmation explains calls/drafts and restart before continuation.
- Missing official Vencord installation/repair is offered in the same overlay with explicit consent. Unsupported installations are explained there and cannot continue.
- Recovery disable/restore also require confirmation. Backups, integrity checks and unrelated themes/plugins/QuickCSS preservation remain unchanged.
- Confirmations are bound to the reviewed configuration and are single-use; changes, stale tokens and repeated clicks cannot apply a different or duplicate operation.

Checks: 57 core, 40 browser and 36 native Windows checks; Release packaging. Native confirmation tests use a safe simulation with no real Discord writes/restart. Screenshots show the actual Windows embedded renderer and review overlay. Clean-machine Vencord setup/live application, signing and exhaustive accessibility/performance coverage remain open.

Close an older launcher before opening this Windows x64 beta. Existing `.dtheme` files remain compatible. WebView2 Runtime is required; .NET, editor assets and notices are bundled. The executable remains unsigned. Changes affect the local client only; other members adopt shared configurations themselves.
