# 0.3.0 beta 13 — Lower editor allocations and lighter artwork

Theme editing creates less temporary memory, and new image imports use fewer decoded pixels. This release builds on beta.12 and retains saved themes, duplication, named palettes, on-demand fonts, reviewed CSS import and multiple server/DM targets.

## Changes

- Cache the verified bundled presets and parsed catalog instead of rereading and hashing them repeatedly during edits.
- Keep image payloads out of repeated CSS rewrites and insert custom artwork after the remaining changes. Local compiler measurements show **86% fewer allocations for the preset case** and **63% fewer for the two-image case**. These are editor compilation allocations, not a promised Discord RAM reduction.
- Downscale new PNG/JPEG imports to at most **1920 px per side and 2,073,600 pixels**, preserving proportions and transparency. Existing portable/library images remain unchanged; re-import large images to receive the reduction.
- Remove the unused response history from the legacy preview. Preserve the main Studio resource-retention fix already released in beta.12.
- Remove the invisible board-photo box below the existing chat-width threshold.

## Download and upgrade

Download **DiscordThemeLauncher-0.3.0-beta.13-windows-x64-portable.zip**, extract it and run `DiscordThemeLauncher.exe` normally. Close the older launcher first. Local libraries, saved configurations and recovery history remain in the Windows user profile. There is no configuration migration or automatic theme application.

The standalone EXE is also available. Both bundle .NET, require Microsoft Edge WebView2 Runtime and remain **unsigned**. The portable ZIP includes runtime, font and theme notices. Changes apply only to the local client.

## Validation and limits

Local validation: **142 Core checks, 72 browser tests and 90 native Windows checks**. Native checks use actual WebView2 and temporary profiles, including image reductions, imported-theme compatibility, saving/reopening and application confirmations. Release assets come from the successful Windows CI job for the tagged source and include SHA-256 checksums.

[Performance audit and measurement limits](https://github.com/PrimeBuild-pc/discord-theme-launcher/blob/v0.3.0-beta.13/docs/PERFORMANCE-AUDIT.md). Pixel-buffer limits do not represent total browser/GPU memory. Long gaming sessions, clean-machine setup and every hardware/driver combination are not certified. This release makes no claim to fix Call of Duty or driver watchdog crashes.
