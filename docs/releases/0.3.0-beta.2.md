# 0.3.0 beta 2 — A clearer preview, a better studio

The launcher now opens **Theme Studio**, a redesigned offline editor with Discord-inspired dark surfaces, blurple accents, embedded Noto Sans typography and consistent controls.

- Separate **Server**, **Style**, **Artwork** and **Recovery** sections replace the long scrolling form.
- Starting preset cards load the matching font, palette, banner and background together. Artwork choices show real bundled thumbnails.
- **Your server / Other server / DMs** are clearly labeled preview contexts. Stock Discord outside the target is intentional and is explained beside the preview.
- The preview fills its panel; messages scroll inside the chat while the composer remains visible. No reduced browser zoom or white native scrollbars in the editor.
- Invalid targets and loading failures appear over the preview rather than leaving an unexplained stale view. Rapid changes settle on the latest selected design.
- Save/share, native file dialogs, asset/license validation, backups and reversible managed-theme transactions are retained. Existing `.dtheme` files remain compatible.

Validation: **34 browser tests, 57 Windows / 58 Linux core checks and 22 native Windows checks**. Native tests exercise the actual embedded studio, real artwork/font loading, preset selection through the host bridge, isolation status, invalid-target recovery, rapid changes and navigation blocking. Screenshots capture the real Windows embedded renderer with synthetic conversations.

Download/extract the Windows x64 portable ZIP and run the EXE normally. Close an older launcher window before opening this version. Microsoft Edge WebView2 Runtime is required; .NET and editor assets are bundled. No Discord token or credentials are requested. The client is restarted only after explicit calls/drafts acknowledgement when applying, disabling or restoring.

Changes affect your local client; other members adopt a shared configuration themselves. This is an independent Prime Build project, not an official Discord plugin. The EXE remains **unsigned**. Fresh-machine Vencord setup, live personal-theme application, exhaustive accessibility/DPI checks and performance/call benchmarks remain outside this update's validation. The user's running Discord was not restarted during development.
