# JetBrains Mono display font

Unmodified upstream Medium WOFF2; SIL Open Font License 1.1.

Font: https://raw.githubusercontent.com/JetBrains/JetBrainsMono/19371302b95d218af43299bce79ddbddd0bc364d/fonts/webfonts/JetBrainsMono-Medium.woff2

License: https://raw.githubusercontent.com/JetBrains/JetBrainsMono/19371302b95d218af43299bce79ddbddd0bc364d/OFL.txt

The supplied Medium face has upstream OS/2 weight 436. The CSS alias maps this fixed face to weight 500 without changing font bytes. Artwork outlines are generated from these exact bytes using scripts/extract-font-glyphs.py and fontTools 4.63.0. No system font installation is required.
