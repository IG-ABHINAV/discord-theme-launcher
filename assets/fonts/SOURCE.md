# Launcher typography

Unmodified Noto Sans Regular and Bold, licensed under SIL OFL 1.1.

Source: https://github.com/notofonts/noto-fonts/tree/ffebf8c1ee449e544955a7e813c54f9b73848eac/hinted/ttf/NotoSans

The launcher prefers an existing installed gg sans family and otherwise loads these embedded fallback fonts locally. It does not install fonts system-wide or download Discord fonts.
