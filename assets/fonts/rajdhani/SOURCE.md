# rajdhani display font

Unmodified upstream WOFF2, weight 500; SIL Open Font License 1.1.

Font: https://fonts.gstatic.com/s/rajdhani/v17/LDI2apCSOBg7S-QT7pb0EPOreec.woff2

License: https://raw.githubusercontent.com/google/fonts/fbe81817505e8aeadc53cc7a38a2b76fb57c333e/ofl/rajdhani/OFL.txt

Google Fonts CSS source: https://fonts.googleapis.com/css2?family=Rajdhani:wght@500&display=swap

The upstream Latin subset covers the Italian UI; unsupported glyphs retain native fallback fonts.

Artwork outlines are generated from these exact bytes using scripts/extract-font-glyphs.py and fontTools 4.63.0. No system font installation is required.
