# FantaFort display typography

Unmodified Bangers Regular by the Bangers Project Authors, under SIL OFL 1.1.

Source: https://github.com/google/fonts/tree/c13390277dfb1fcc7415d84ef7ef9cfc1e52f8c1/ofl/bangers

The theme embeds the unmodified font for server headings and navigation. Artwork uses static outlines generated from this font. No proprietary Fortnite font is bundled. Regenerate glyphs.json using scripts/extract-font-glyphs.py with fontTools 4.63.0.
